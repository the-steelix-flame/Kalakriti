# Why this is a copy and not an include
# -------------------------------------
# This file started as one line - `-r backend/requirements.txt` - which is the right
# way to avoid two lists, and it does not work here. A Space does not copy the
# repository before installing; it bind-mounts this single file at
# /tmp/requirements.txt and runs pip against it. `-r` resolves relative to the file,
# so pip went looking for /tmp/backend/requirements.txt, which was never mounted:
#
#   ERROR: Could not open requirements file:
#   [Errno 2] No such file or directory: '/tmp/backend/requirements.txt'
#
# So the list is inlined. The preflight check exists because a copy nobody verifies
# is a copy that is wrong within a fortnight - and the failure mode is nasty: the
# Space installs a different version from every laptop, and the bug only appears in
# production.
